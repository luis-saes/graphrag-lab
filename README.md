# graphrag-lab

Building a new GraphRAG system e2e:
Documents > LLM Entity Extraction > Neo4j Knowledge Graph > Vectorial Retrieval + Hybrid Graph > Agentic Answers

The main objective is the measurement. Every retrieval must be evaluated with recall@10 and answer truthfully against a set of questions. The finished system is benchmarked versus a vector-only baseline on multi-hop questions.
